## Projetos

### [FakeMiner](https://github.com/Lucaskalell/fake-miner)
`Spring Boot` `Angular` `Flutter`

Monitor de hardware com um minerador de criptomoedas simulado. Coleta métricas reais da máquina, dispara alertas escalonados no Telegram por meio de uma máquina de estados e expõe tudo para um painel web e um app mobile. Tem testes nos três módulos e CI no GitHub Actions.

### [Oficina Conectada](https://github.com/Lucaskalell/oficina-conectada)
`Spring Boot` `Flutter`

Gestão de oficina mecânica voltada para o cliente, com estimativa de tempo de serviço e notificação de status. Projeto começado na fase de estudos e mantido como registro de evolução: recebe atualizações conforme aprendo coisas novas, então partes dele ainda refletem decisões antigas. Não tem fins comerciais. O front-end Flutter está em [oficina-conectada-front](https://github.com/Lucaskalell/oficina-conectada-front).
